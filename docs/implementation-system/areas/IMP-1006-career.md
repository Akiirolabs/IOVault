# IMP-1006 — Career

**State:** Partial · **Priority:** P2

The current page edits a resume and produces an AI draft. The target connects claims to evidence and tracks each application deliberately.

## Steps

1. Define reusable experience, accomplishment, skill, resume-version, and application records.
2. Link accomplishments to projects and learning evidence.
3. Add job-specific tailoring with visible source records and reviewable changes.
4. Add application status, follow-ups, and export-safe resume versions.

**Acceptance:** AI never invents unsupported claims; every tailored version retains its source and history; current resume content migrates unchanged.

**Limits:** automated job submission, inbox scraping, and employer-system integrations are deferred.

## Engineering dependencies

Storage, sync, UI boundaries, validation, and AI abuse controls are linked in [engineering dependencies](../engineering-dependencies.md); their implementation status is not duplicated here.
