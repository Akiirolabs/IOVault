## Completion gate

EDEP-1002 is complete when the deployed Career Agent can connect and revoke a real Google account, refresh expired access, recover from partial consent, create one exact approved Gmail draft and Calendar event without duplication, and accurately limit every marketplace workflow to authorized provider capabilities.

Secrets, OAuth tokens, provider content, résumés, and private career records must never be stored in this document, source control, `VaultState`, or browser storage.
