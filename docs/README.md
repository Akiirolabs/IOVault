# IO Vault Docs

This folder tracks what has been implemented, what changed, and what is planned next. Update it alongside code changes so the docs stay aligned with the app.

## Files

- [Architecture and implementation map](architecture.md): current app structure, data flow, styling rules, and file responsibilities.
- [Diagrams](diagrams.md): Mermaid diagrams for the app flow, data flow, component layout, and responsive layout behavior.
- [Implementation log](implementation-log.md): dated notes for completed changes and verification.
- [Roadmap](roadmap.md): planned work and implementation notes for upcoming changes.

## Documentation Rule

When making a code change, update at least one of these docs:

- Update `implementation-log.md` for completed work.
- Update `architecture.md` when file responsibilities, data flow, storage, API contracts, or layout rules change.
- Update `diagrams.md` when user flow, architecture, or responsive behavior changes.
- Update `roadmap.md` when planned work is added, changed, or completed.
