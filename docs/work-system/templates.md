# Work Record Templates

| Code | Required record |
|---|---|
| `IMP` | Page, problem, rollout children, state, acceptance, limits, dependencies |
| `DBG` | Evidence, impact, cause, status, linked correction |
| `DBG-IMP` | Source DBG/ADT, changes, verification, limitations |
| `ADT` | Scope, method, findings, evidence, correction links |
| `FTR` | Page, manual source code/date, numbered findings, correction links |
| `FTR-IMP` | Source findings, changes, user-visible verification |
| `DOC` | Documentation need, affected authorities, validation |
| `DPL` | Included work, test/build evidence, environment, database, result, monitoring, rollback |

Every record includes its code, status, started date, finished date when verified, and concise outcome.
